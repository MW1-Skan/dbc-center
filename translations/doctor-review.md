# Arabic copy awaiting Dr. Karam

These 33 strings are medical content and were left in English on purpose. In
`messages/ar.json` each one still carries the `[AR] ` prefix, which the Arabic pages show as-is.

How to use this file: write the Arabic next to each row (or reply with key → Arabic), then we
replace the value in `messages/ar.json`. Rules that apply to the Arabic text:

- Western digits (0-9) for every number; keep `[square-bracket]` placeholders as brackets and
  translate the words inside them (e.g. `[X days]` → `[X أيام]`).
- Keep the tags `<strong>…</strong>` and the placeholder `{line}` exactly where they are in
  `BookPage.emergency`.
- Glossary: `translations/GLOSSARY.md` (تكميم المعدة، تحويل مسار المعدة، طي المعدة، بالون المعدة…).
- The two biography paragraphs and the home-page bio are drafts for approval in English too, so the
  Arabic can be written freely rather than translated word for word.
